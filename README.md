# Validify

Validify is a reusable Python library for validating common user inputs.

## Features
- Email validation
- Password strength checking
- Phone number validation
- URL validation
- Username validation
- Required-field checking
- Numeric-range validation

## Example
```python
from validify import validate_email
print(validate_email("student@gmail.com"))
```

## Run locally
```bash
pip install -e .
python example.py
```
